# Créditos

Os guias deste pacote são uma adaptação dos guias de up do **RestedXP**
para o WoW: Forever (https://github.com/RestedXP/RXPGuides), licenciados sob
Creative Commons Atribuição-NãoComercial-CompartilhaIgual 4.0 (CC BY-NC-SA 4.0).

Alterações: conversão automática para o formato do Azimute (tools/rxp2azimute.py);
textos livres em inglês mantidos só para o cliente enUS; comandos sem
equivalente removidos. Este pacote é distribuído gratuitamente, sob a mesma
licença (ver LICENSE.txt). O RestedXP não endossa o Azimute.
