# Como contribuir / How to contribute

## Português

O Azimute é um projeto pequeno e as contribuições mais úteis não precisam de código:

- **Reportar problema num passo:** use o botão de inseto na janela do guia (ou `/azimute reportar`),
  copie o texto e cole no canal de suporte do projeto. Escreva o que aconteceu na última linha.
- **Traduzir:** a interface fica em `Azimute/Locales.lua`; as dicas dos guias, em `tools/translations/`.
  Nomes de missão, NPC, item e zona vêm do próprio jogo, então não precisam de tradução.
- **Guias da comunidade:** grave uma rota com `/azimute gravar`, revise o texto e compartilhe o código
  `!AZ1!`. Guias enviados ao projeto precisam ser **seus** (não copie Zygor, RestedXP ou outros sem a
  licença permitir) e são publicados sob **CC BY-SA 4.0**, em pacote separado dos guias do RestedXP.
- **Código:** abra uma issue antes de mandar um pull request grande. Ao enviar código, você concorda que
  ele seja distribuído sob a GPL-3.0-or-later **e** que o autor do projeto possa relicenciá-lo no futuro
  (por exemplo, numa versão com outra licença). Se não concorda com isso, prefira contribuir com
  traduções, guias e relatórios.

## English

Most useful contributions don't need code:

- **Report a problem in a step:** use the bug icon on the guide window (or `/azimute reportar`), copy
  the text and paste it in the project's support channel. Say what happened on the last line.
- **Translate:** UI strings live in `Azimute/Locales.lua`; guide tips in `tools/translations/`.
  Quest, NPC, item and zone names come from the game client, so they need no translation.
- **Community guides:** record a route with `/azimute gravar`, review the text and share the `!AZ1!`
  code. Guides sent to the project must be **yours** (don't copy Zygor, RestedXP or others unless their
  license allows it) and are published under **CC BY-SA 4.0**, in a package separate from the
  RestedXP-based guides.
- **Code:** open an issue before sending a large pull request. By sending code you agree it is
  distributed under GPL-3.0-or-later **and** that the project author may relicense it in the future
  (for example in a version under different terms). If you don't agree, contribute translations,
  guides and reports instead.
