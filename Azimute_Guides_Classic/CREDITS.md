# Créditos

As rotas deste pacote são uma adaptação dos guias **Guidelime_Zarant**, de Zarant
(https://github.com/jaydeshow/Guidelime_Zarant), licenciados sob a GNU GPL v3.

Alterações: conversão automática para o formato do Azimute (tools/guidelime2azimute.py),
só os níveis 30-60; dicas traduzidas para pt-BR. Este pacote é distribuído sob a mesma
licença GPL v3 (ver LICENSE.txt). As rotas foram feitas para o Classic: algumas missões
podem ter mudado no WoW: Forever.
